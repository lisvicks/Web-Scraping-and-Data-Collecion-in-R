# Web-Scraping-and-Data-Collecion-in-R
This project demonstrates static and dynamic web scraping in R using `rvest` and `RSelenium`.

The project includes:

- scraping article and comment data from paginated web pages;
- extracting a JavaScript-rendered company rankings table;
- browser automation with RSelenium;
- data cleaning and standardization;
- preparation of analysis-ready datasets.

## Files

- `web_scraping.qmd` — source code and analysis
- `web_scraping.html` — rendered project output
- `data/` — collected and cleaned datasets, video

## Tools

R, rvest, RSelenium, dplyr, stringr, lubridate
